# Loop

## analyse
analyse the codebase to find bugs/issues and add them to CodeMax.md as Tasks to fix.

## unit tests
Check coverage, improve existing tests.
If we need a new unit test, Create a Task in CodeMax.md for it.

## Fix
Work throught the bugs/issues you found and check them off as you fix them.
Repeat the Fix stage until all Tasks are done.

## CodeMax.md
Clean up CodeMax.md after the sweep and fixes are done.

## Documentation
Check ./docs/*.md for issues and fix them.
Update Readme.md to be clear for developer using daedalus lib.

Once all these items are done, you may Stop.
